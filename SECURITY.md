# Security Policy

If you discover a security vulnerability in this project, please report it privately to the maintainer by emailing kubik13defence@gmail.com rather than opening a public GitHub issue. Include a clear description of the vulnerability, steps to reproduce it, the affected component or version, and any suggested mitigations. The maintainer will acknowledge your report as soon as possible, investigate the issue, and coordinate a fix and disclosure timeline with you. Please do not disclose the vulnerability publicly until a patch has been released.
